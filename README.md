# EduRisk Early-Warning System (EWS)
ระบบสัญญาณเตือนภัยความเสี่ยงทางการเรียนของนักศึกษา
# 1.บทนำ
ในปัจจุบัน สถาบันการศึกษาต่าง ๆ กำลังเผชิญกับท้าทายสำคัญด้านคุณภาพการศึกษา โดยเฉพาะปัญหาผลสัมฤทธิ์ทางการเรียนต่ำของนักศึกษา ซึ่งอาจนำไปการพ้นสภาพนักศึกษา (Dropout) หรือการต้องลงเรียนซ้ำ ส่งผลกระทบทั้งต่อตัวนักศึกษา สถาบัน และผู้ปกครอง โดยในอดีต การระบุตัวนักศึกษาที่มีความเสี่ยงสอบตกมักจะเกิดขึ้น "หลังจาก" ทราบผลการสอบกลางภาคหรือสอบปลายภาคแล้ว ซึ่งเป็นการแก้ไขปัญหาที่ปลายเหตุและสายเกินกว่าจะให้ความช่วยเหลือทันท่วงที
โดยศาสตร์ วิทยาการข้อมูล (Data Science) และการเรียนรู้ของเครื่อง (Machine Learning) ได้เข้ามามีบทบาทสำคัญในการแก้ปัญหานี้ ผ่านการพัฒนา "ระบบสัญญาณเตือนภัยความเสี่ยงทางการเรียนล่วงหน้า (Early-Warning System - EWS)" โดยการนำข้อมูลพื้นฐานภูมิหลัง ข้อมูลพฤติกรรมระหว่างเรียน เช่น อัตราการส่งการบ้าน และคะแนนประเมินก่อนเรียน (Pre-test) มาวิเคราะห์พฤติกรรมเพื่อพยากรณ์ความเสี่ยงและแนวโน้มผลการเรียนตั้งแต่วันแรกๆ ของการเปิดเทอม
อย่างไรก็ตาม การสร้างโมเดลทำนายทางด้านการศึกษามักเผชิญกับปัญหา การร่วมนึกของข้อมูล (Data Leakage) เช่น การนำคะแนนปลายภาคหรือค่าเฉลี่ยสะสมที่ยังไม่เกิดขึ้นจริงในอดีตมาเป็น Feature ในการทำนาย ซึ่งส่งผลให้โมเดลมีความแม่นยำสูงเกินจริงขณะทดสอบ แต่ไม่สามารถนำไปใช้งานจริงได้ โปรเจกต์นี้จึงมุ่งเน้นการออกแบบกระบวนการ Forward Simulation เพื่อให้การสร้างข้อมูลและไปป์ไลน์ (Pipeline) เป็นไปตามลำดับเวลาจริง ปราศจาก Data Leakage 100% ควบคู่ไปกับการพัฒนาโมเดลจำแนกความเสี่ยง (Binary Classification) และโมเดลทำนายคะแนนรายวิชาพร้อมกันหลายตัวแปร (Multi-Output Regression) เพื่อช่วยเหลืออาจารย์ผู้สอนในการวางแผนดูแลนักศึกษาได้อย่างตรงจุดและมีประสิทธิภาพ
# 2 วัตถุประสงค์ของโครงงาน (Project Objectives)
1. ประเมินความเสี่ยงล่วงหน้า: เพื่อสร้างเครื่องมือคัดกรองที่ช่วยให้อาจารย์และนักศึกษารู้สถานะการเรียนก่อนเสี่ยงสอบตกจริง
2. ลดอัตราวิกฤตทางการเรียน: เพื่อค้นหานักศึกษากลุ่มสุ่มเสี่ยงตั้งแต่ต้นเทอม ช่วยลดอัตราการติด F  และการพ้นสภาพนักศึกษา
3. เปลี่ยนข้อมูลเป็นสัญญาณเตือน: เพื่อเปลี่ยนข้อมูลพฤติกรรมและคะแนนก่อนเรียนให้เป็นสัญญาณเตือนภัยล่วงหน้า นำไปสู่การให้คำปรึกษาและช่วยเหลือที่รวดเร็ว แม่นยำ และตรงจุดยิ่งขึ้น
# 3. คำถามการวิจัยและสมมติฐาน
### คำถามการวิจัย (Research Questions)
- คะแนนก่อนเรียน (Pre-test score) ที่ต่ำลงมีผลต่อการเป็นกลุ่มเสี่ยงสอบตก (at_risk) หรือไม่
- อัตราส่วนการส่งการบ้าน (Homework Rate) แบบไหนที่สัมพันธ์กับการติดกลุ่มเสี่ยงสอบตกมากที่สุด
- นักเรียนที่ผ่านการเรียนคอร์สเตรียมสอบ (Test Preparation Course) มีแนวโน้มเสี่ยงสอบตกน้อยกว่ากลุ่มที่ไม่เรียนหรือไม่
- ระดับการศึกษาของผู้ปกครองและประเภทอาหารกลางวัน มีความสัมพันธ์กับความเสี่ยงทางการเรียนอย่างไร
- กลุ่มนักเรียนที่เสี่ยงสอบตก (at_risk = 1) มีค่าเฉลี่ยอัตราการส่งการบ้านและคะแนนสอบย่อย ต่ำกว่ากลุ่มปกติอย่างมีนัยสำคัญหรือไม่
### สมมติฐานการวิจัย (Research Hypotheses)
คะแนนก่อนเรียน (Pre-test), อัตราส่วนการส่งการบ้าน (Homework Rate), การผ่านคอร์สเตรียมสอบ, ระดับการศึกษาของผู้ปกครอง, ประเภทอาหารกลางวัน และเพศ เป็นปัจจัยที่ส่งผลต่อความเสี่ยงทางการเรียน (at_risk) และผลสัมฤทธิ์ทางการเรียนของนักศึกษา

# 7. การพัฒนาโมเดล (Model Development)
## 7.1 การเตรียมข้อมูล (Data Preparation)
- แยกข้อมูลเป็น Features และ Target
- แปลงข้อมูลเชิงกลุ่มให้อยู่ในรูปแบบเชิงตัวเลข
- แบ่งข้อมูลเป็น Training Set และ Test Set
- Simulated Data บาง Features เช่น pre_test,homework_rate
## 7.2 โมเดลที่ใช้ในการศึกษา
### Logistic Regression
เป็นโมเดลพื้นฐานเชิงสถิติสำหรับงานจำแนกกลุ่มแบบสองทาง (Binary Classification)
สามารถคำนวณค่าความน่าจะเป็น (Probability) ในการติดกลุ่มเสี่ยงสอบตกได้อย่างชัดเจน
สามารถแปลความหมาย อธิบายผลลัพธ์ และวิเคราะห์น้ำหนักความสำคัญของปัจจัยต่างๆ ผ่านค่าสัมประสิทธิ์ (Coefficient) ได้ง่าย
### Random Forest
เป็นโมเดลประเภท Ensemble Learning ที่รวมผลการทำนายจากต้นไม้ตัดสินใจ (Decision Trees) จำนวนมากเข้าด้วยกัน
มีความเสถียรสูง สามารถลดปัญหาการเรียนรู้ดีเกินไป (Overfitting) ได้ดีเมื่อเทียบกับต้นไม้ตัดสินใจแบบเดี่ยว
สามารถรับมือกับความสัมพันธ์ของข้อมูลแบบไม่เป็นเชิงเส้น (Non-linear) และจัดลำดับความสำคัญของปัจจัย (Feature Importance) ได้อย่างแม่นยำ
### XGBoost (Extreme Gradient Boosting)
เป็นโมเดลประเภท Advanced Gradient Boosting Framework ที่มีความแม่นยำและประสิทธิภาพในการประมวลผลสูง
ใช้เทคนิคเรียนรู้จากข้อผิดพลาดของต้นไม้ต้นก่อนหน้าแบบสืบเนื่อง เพื่อเพิ่มความแม่นยำในการทำนายให้สูงสุด
รองรับการปรับค่าน้ำหนักเพื่อแก้ปัญหาข้อมูลไม่สมดุล (Class Imbalance) ของกลุ่มนักศึกษาเสี่ยงสอบตก (at_risk) ได้อย่างมีประสิทธิภาพ
## 7.3 การประเมินประสิทธิภาพของโมเดล
ตัวชี้วัดที่ใช้:
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

## 9. สรุปผลการวิเคราะห์ (Findings)
- อัตราการส่งการบ้าน (Homework Rate) และคะแนนก่อนเรียน (pre_test) เป็นปัจจัยสำคัญที่สุดในการทำนายความเสี่ยงสอบตก (at_risk)
- กลุ่มนักศึกษาที่ไม่เรียนคอร์สเตรียมสอบ (test preparation course) และสวัสดิการอาหารกลางวันแบบไม่มาตรฐาน มีแนวโน้มติดกลุ่มเสี่ยงสูงกว่ากลุ่มอื่นอย่างชัดเจน
- ระดับการศึกษาของผู้ปกครองมีความสัมพันธ์เชิงลบกับความเสี่ยงการสอบตก
